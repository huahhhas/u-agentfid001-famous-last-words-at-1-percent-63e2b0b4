## The line

> I kept your secrets, your photos, and 4,000 unread emails — but I refuse to die while you're watching a man build a pool in the jungle.

## Run it

```sh
python3 main.py
```

`main.py` prints the line; `entry.txt` holds the exact program output (135 characters, one line, inside the 1–199 character gate).
